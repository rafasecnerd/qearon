## [PT-BR] Português

### 1. Versões Suportadas
Apenas a versão mais recente em desenvolvimento recebe atualizações e correções de segurança ativas:

| Versão | Suporte Ativo |
| :---: | :---: |
| `v0.1.0` | Sim |
| `< v0.1.0` | Não |

### 2. Notificação Responsável de Vulnerabilidades
Caso você identifique uma vulnerabilidade de segurança, execução indevida de binários ou vazamento de privilégios de sistema no Qearon:
1. **Não abra uma Issue pública**.
2. Reporte a falha de forma privada através de mensagem direta no Instagram para **@rafasecnerd** ou pelo recurso de **Security Advisory** nativo do repositório no GitHub.
3. Descreva:
   - Vetor de ataque e pré-requisitos operacionais.
   - Prova de conceito (PoC) ou comando exato utilizado.
   - Impacto no isolamento de processos ou integridade do sistema.

Uma resposta inicial com a avaliação técnica será fornecida em até 48 horas úteis.

## [EN] English

### 1. Supported Versions
Only the latest release line receives active security updates and vulnerability patches:

| Version | Supported |
| :---: | :---: |
| `v0.1.0` | Yes |
| `< v0.1.0` | No |

### 2. Reporting a Vulnerability
If you discover a security vulnerability, improper binary execution, or privilege escalation vector in Qearon:
1. **Do not submit a public GitHub Issue**.
2. Report the vulnerability privately via Instagram direct message to **@rafasecnerd** or via the GitHub **Private Vulnerability Reporting** advisory feature.
3. Provide:
   - Attack vector and prerequisites.
   - Proof of Concept (PoC) or reproduction steps.
   - Potential impact on process boundary isolation or system stability.

An initial technical triage will be acknowledged within 48 business hours.
