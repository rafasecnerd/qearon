## [PT-BR] Português

Este diretório mantém a documentação técnica formal do **Qearon**, auditada e sincronizada diretamente com a base de código em Zig.

### Arquitetura C4 da AST
- [`diagrama_c4_ast.md`](diagrama_c4_ast.md): Diagrama C4 (Contexto, Contêineres e Componentes) gerado a partir da árvore sintática abstrata (AST) do projeto.

### Documentos Técnicos em Português (`docs/pt-br/`)
1. [`arquitetura.md`](pt-br/arquitetura.md): Estrutura do monorepo linear, divisão modular e integração ALSA/PipeWire.
2. [`manual_uso.md`](pt-br/manual_uso.md): Guia de operação em linha de comando, parâmetros e fluxos práticos.
3. [`regras_desenvolvimento.md`](pt-br/regras_desenvolvimento.md): Padrão de código 1TBS, tipagem estrita, ausência de dependências externas e convenções Zig.
4. [`guia_solucao_problemas.md`](pt-br/guia_solucao_problemas.md): Matriz de classificação de falhas, eliminação de ruído analógico e calibragem de microfone.
5. [`resiliencia_e_erros.md`](pt-br/resiliencia_e_erros.md): Mecanismos de tolerância a falhas, modo híbrido de contingência e degradação suave.

## [EN] English

This directory maintains the formal technical documentation of **Qearon**, audited and synchronized directly with the underlying Zig codebase.

### C4 AST Architecture
- [`diagrama_c4_ast.md`](diagrama_c4_ast.md): C4 Model diagrams (Context, Containers, Components) mapped from the project Abstract Syntax Tree (AST).

### Technical Documents in English (`docs/en/`)
1. [`architecture.md`](en/architecture.md): Linear monorepo architecture, modular decomposition, and ALSA/PipeWire integration.
2. [`user_manual.md`](en/user_manual.md): Command-line operational guide, parameters, and practical workflows.
3. [`development_rules.md`](en/development_rules.md): 1TBS coding standards, strict typing, zero third-party dependencies, and Zig rules.
4. [`troubleshooting_guide.md`](en/troubleshooting_guide.md): Failure classification matrix, analog bleed elimination, and microphone calibration.
5. [`resilience_and_errors.md`](en/resilience_and_errors.md): Fault tolerance mechanisms, fallback contingency modes, and graceful degradation.
