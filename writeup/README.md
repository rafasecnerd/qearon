## [PT-BR] Português

Este diretório contém os artigos acadêmicos e monografias científicas detalhando o processo de engenharia de software de baixo nível, a história da computação sonora em Linux e as decisões arquiteturais do projeto **Qearon**.

### Estrutura de Arquivos
- [`pt-br/artigo_tecnico_qearon.md`](pt-br/artigo_tecnico_qearon.md): Artigo científico em língua portuguesa com fundamentação teórica, análise de registradores ALSA e estudo de caso empírico.
- [`en/qearon_technical_paper.md`](en/qearon_technical_paper.md): Artigo científico espelhado em inglês formal com as mesmas referências e rigor metodológico.

## [EN] English

This directory contains formal academic papers and scientific monographs documenting low-level systems engineering, the historical evolution of Linux audio stacks, and architectural decisions behind the **Qearon** system.

### File Structure
- [`pt-br/artigo_tecnico_qearon.md`](pt-br/artigo_tecnico_qearon.md): Scientific paper in Portuguese featuring theoretical foundations, ALSA register analysis, and empirical case studies.
- [`en/qearon_technical_paper.md`](en/qearon_technical_paper.md): Mirrored scientific paper in formal English featuring identical academic references and methodological rigor.
