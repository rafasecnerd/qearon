## [PT-BR] Português

### 1. Canal Oficial de Suporte
Dúvidas técnicas, problemas de detecção de hardware ou orientações de configuração devem ser encaminhados diretamente via mensagem privada no Instagram:

- **Instagram**: [https://instagram.com/rafasecnerd](https://instagram.com/rafasecnerd) (`@rafasecnerd`)

### 2. Abertura de Issues no GitHub
Para problemas reprodutíveis no código ou bugs de compilação:
- Verifique primeiramente o [`guia_solucao_problemas.md`](docs/pt-br/guia_solucao_problemas.md).
- Se o problema persistir, abra uma **Issue** no GitHub utilizando nosso modelo oficial de reporte de bugs, anexando a saída de `qearon status` e `cat /proc/asound/card*/codec#*`.

## [EN] English

### 1. Official Support Channel
Technical inquiries, hardware detection issues, or setup assistance should be directed to the project maintainer via direct message on Instagram:

- **Instagram**: [https://instagram.com/rafasecnerd](https://instagram.com/rafasecnerd) (`@rafasecnerd`)

### 2. GitHub Issues
For reproducible bugs or build errors:
- First consult the [`troubleshooting_guide.md`](docs/en/troubleshooting_guide.md).
- If the issue persists, file a **GitHub Issue** utilizing our official bug report template, attaching the output of `qearon status` and `cat /proc/asound/card*/codec#*`.
